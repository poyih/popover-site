Popover Support

Popover answers the system-wide Translate action on iPhone and iPad with Apple’s Foundation Models: the on-device model, and Private Cloud Compute on iOS 27.

Requirements

An iPhone or iPad that supports Apple Intelligence, running iOS 26 or later, with Apple Intelligence turned on in Settings and the on-device model downloaded.

Private Cloud Compute needs iOS 27, a network connection and remaining daily quota. On iOS 26 every translation runs on the device.

Set Popover as the default translator

Open Settings ▸ Apps ▸ Default Apps ▸ Translation and choose Popover. The Popover app’s Settings ▸ Help row opens this screen for you.

Then select any text in Safari, Notes, Mail or another app and tap Translate in the edit menu. Popover’s sheet appears with the translation and, where the host app allows it, a Replace button.

Deleting Popover resets the default translation app to Apple’s Translate. After reinstalling, pick Popover again in the same Settings screen.

Engines

Automatic (default) tries Private Cloud Compute first and falls back to the on-device model when the cloud is unavailable.

Cloud Only never falls back; it shows an error when Private Cloud Compute cannot answer. Switch the engine in Popover’s Settings to translate right away.

On-Device Only keeps every translation on your device.

Common questions

No Translate item in the edit menu: the host app has not offered the system Translate action for that selection, or Popover is not the default translator yet.

“Needs attention” on the Status tab: turn on Apple Intelligence in Settings and wait for the on-device model to finish downloading, then return to Popover.

Replace is missing: the host app did not allow replacement for that selection. Use Copy instead.

Translation refused: the model declined the selected content. This is not a quota problem; Automatic does not fall back for refusals.

Privacy

Popover has no servers, accounts, ads or analytics. Read the privacy policy for how the on-device model and Private Cloud Compute handle your text.
