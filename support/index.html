Popover Support

Popover translates selected text through the system Translate action in supported apps on iPhone and iPad. It uses Apple Intelligence on your device or through Private Cloud Compute.

Requirements

Use an iPhone or iPad that supports Apple Intelligence, running iOS 26 or iPadOS 26 or later, with Apple Intelligence enabled. The on-device model must be ready for on-device translation.

Private Cloud Compute requires iOS 27 or iPadOS 27 or later, a network connection and remaining daily quota. On iOS 26 and iPadOS 26, Automatic and On-Device Only use the on-device model; Cloud Only is unavailable.

Set Popover as the default translation app

Open Settings ▸ Apps ▸ Default Apps ▸ Translation and choose Popover. In Popover, the Setup Guide row in Settings shows these steps. Its Open Settings button opens Popover’s system settings page; go back to Apps, then open Default Apps ▸ Translation.

In an app that offers the system Translate action, select text and tap Translate. Popover displays the translation. Replace becomes available after a successful translation if the original app allows replacement for that selection.

Deleting Popover resets the default translation app to Apple’s Translate. After reinstalling, choose Popover again in the same Settings screen.

Engines

Automatic, the default, uses Private Cloud Compute when it’s available and you have quota left. Otherwise, or if a cloud request fails, it uses the on-device model. It doesn’t switch when Apple Intelligence declines the text.

Cloud Only never switches to the on-device model. It shows an error when Private Cloud Compute cannot answer. You can try choosing On-Device Only in Popover Settings, then translating again if that model is ready.

On-Device Only processes every translation on your device and works offline once the model is ready.

Common questions

No Translate item in the edit menu: the original app may not offer the system Translate action for that selection. Try selecting text in another app. If Translate opens Apple’s Translate app instead, check that Popover is selected as the default translation app.

“Needs attention” on the Status tab: the line under the title names the problem, for example an unsupported device, Apple Intelligence turned off, or a model that isn’t ready yet.

Replace is unavailable: wait until translation finishes. The button also remains disabled after an error or when the original app does not allow replacement. You can copy a completed translation instead.

“Apple Intelligence declined to translate this text”: Automatic doesn’t switch to the on-device model in this case. Try a different selection.

Privacy

Popover has no developer-operated translation servers, accounts, ads or analytics. Read the privacy policy for how the on-device model and Private Cloud Compute handle your text.
